# OvOproxy

Windows 下的多 Profile Hosts 切换 + 本地代理轻量工具。

## 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Wails v2 + Go |
| 前端 UI | Vue 3 + TypeScript + Vite + Tailwind CSS |
| 系统集成 | systray (系统托盘)、Windows hosts 编辑 |

## 编译

```batch
.\build.bat
```

编译产物：`release\OvOproxy.exe`
